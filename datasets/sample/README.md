# Fictional integration data

These four shops, four products and five offers are authored test fixtures, not extracted
from the supplied dataset. Import with `--source-kind sample`.
They include duplicate product titles, an unknown location, an unknown price and price timestamp,
a product without an offer, and a shop with only category evidence.
No phone number or real seller identity is included.

Regenerate with `uv run python scripts/create_sample_dataset.py`.
