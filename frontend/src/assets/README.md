# Shared visual assets

`search-hero.jpg` is an illustration-only crop of the user-supplied
`StoreScout/Mobile/10-Landing-Search.png`: source rectangle x=0, y=140,
width=887, height=290; JPEG quality 88. It contains only decorative artwork,
no interface text or controls. The source archive stays outside Git.

`public/fonts/Vazirmatn-Variable.woff2` is the unmodified variable font from
[Vazirmatn v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003/fonts/webfonts).
Its SIL Open Font License is distributed at `public/fonts/OFL.txt`.
The font is self-hosted; no runtime CDN request is made.

Shared icons and the compass brand mark are native SVG in `src/shell/Icon.tsx`.
